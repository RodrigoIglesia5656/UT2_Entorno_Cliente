## 🚀 Cómo usar este repositorio

* **Consulta las soluciones:** Puedes navegar por las carpetas para revisar el código de cada ejercicio después de las clases.
* **Descarga el código:** Si quieres probar el código en tu ordenador, puedes clonar el repositorio usando Git o descargar el contenido en un archivo ZIP desde el botón verde **"Code"** (en GitHub).

⚠️ **Nota importante:** Este repositorio es de **solo lectura** para los estudiantes. No podéis modificar el código directamente ni subir archivos aquí.
